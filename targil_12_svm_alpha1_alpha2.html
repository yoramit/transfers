ניתוח ופתרון אלגוריתם SMO עבור SVM

אלגוריתם SMO (Sequential Minimal Optimization) הוא כלי יעיל ביותר לפתרון בעיית האופטימיזציה הריבועית (QP) הנובעת מניסוח הדואלי של SVM. הרעיון המרכזי הוא פירוק הבעיה הגדולה לתתי-בעיות קטנות ביותר, כאשר בכל שלב אנו מבצעים אופטימיזציה עבור שני כפלי לגרנז' בלבד ($\alpha_1, \alpha_2$), ומחזיקים את כל השאר כקבועים. צעד זה מאפשר פתרון אנליטי מהיר ללא צורך במפתרי QP מורכבים.

(א) צמצום הבעיה לשני משתנים ($\alpha_1, \alpha_2$)

בהינתן בעיית המקסימום הדואלית המקורית, אנו מתייחסים לכל המשתנים $ \alpha_n $ עבור $ n \ge 3 $ כקבועים. נגזור תחילה את אילוץ השוויון החדש:

מתוך אילוץ השוויון הכללי $ \sum_{n=1}^N y_n \alpha_n = 0 $, נפריד את שני האיברים הראשונים:

$$y_1 \alpha_1 + y_2 \alpha_2 + \sum_{n=3}^N y_n \alpha_n = 0$$

נכפיל את שני אגפי המשוואה ב-$y_1$ (נזכור כי $y_1 \in \{-1, +1\}$ ולכן $y_1^2 = 1$):

$$\alpha_1 + y_1 y_2 \alpha_2 + y_1 \sum_{n=3}^N y_n \alpha_n = 0$$

נגדיר את הקבועים כמבוקש: $s = y_1 y_2$ וכן $\gamma = -y_1 \sum_{n=3}^N y_n \alpha_n$. מכאן נקבל את אילוץ הקו הישר המבוקש:

$$\alpha_1 + s \alpha_2 = \gamma$$

כעת, נצמצם את פונקציית המטרה $W(\alpha)$ על ידי בידוד האיברים התלויים ב-1 ו-2 בלבד:

  • איברים ריבועיים טהורים: $-\frac{1}{2} K_{11} \alpha_1^2 - \frac{1}{2} K_{22} \alpha_2^2 - s K_{12} \alpha_1 \alpha_2$ (כאשר השתמשנו ב-$y_1 y_2 = s$).
  • איברים מעורבים (אינטראקציה עם שאר הנתונים הקבועים): $-y_1 \alpha_1 v_1 - y_2 \alpha_2 v_2$, כאשר הגדרנו $v_i = \sum_{j=3}^N y_j \alpha_j K_{ij}$.
  • החלק הליניארי: $\alpha_1 + \alpha_2$.

שילוב כל הרכיבים הללו (והשמטת האיברים התלויים ב-$n \ge 3$ בלבד, כיוון שהם קבועים ולא משפיעים על נקודת המקסימום) נותן לנו בדיוק את הפונקציה המצומצמת:

$$\psi_1(\alpha_1, \alpha_2) = -\frac{1}{2}K_{11}\alpha_1^2 - \frac{1}{2}K_{22}\alpha_2^2 - sK_{12}\alpha_1\alpha_2 - y_1\alpha_1v_1 - y_2\alpha_2v_2 + \alpha_1 + \alpha_2$$

(ב) מציאת נקודת המקסימום האנליטית עבור $\alpha_2$

כדי למצוא את המקסימום ללא אילוצי הקופסה, נציב את האילוץ הליניארי שחולץ בסעיף א': $\alpha_1 = \gamma - s\alpha_2$ לתוך פונקציית המטרה $\psi_1$. נקבל פונקציה $\psi_2(\alpha_2)$ התלויה במשתנה יחיד.

לאחר הצבה ופתיחת סוגריים, נאסוף את המקדמים לפי חזקות של $\alpha_2$:

  • המקדם של $\alpha_2^2$ הוא: $-\frac{1}{2}(K_{11} + K_{22} - 2K_{12}) = -\frac{1}{2}\eta$.
  • המקדם הליניארי של $\alpha_2$ הוא: $s(K_{11} - K_{12})\gamma + y_2(v_1 - v_2) - s + 1$.

נגזור את הפונקציה לפי $\alpha_2$ ונשווה לאפס לקבלת נקודת הקיצון:

$$\frac{d\psi_2}{d\alpha_2} = -\eta \alpha_2 + s(K_{11} - K_{12})\gamma + y_2(v_1 - v_2) - s + 1 = 0$$

נחלץ את $\alpha_2$ ונקבל את הביטוי האנליטי המבוקש:

$$\alpha_2 = \frac{s(K_{11} - K_{12})\gamma + y_2(v_1 - v_2) - s + 1}{\eta}$$

(ג) הוכחת הקשר עבור $v_1 - v_2$

פונקציית החיזוי של המודל במצב הנוכחי (לפני הצעד האופטימלי) מוגדרת כ:

$$f(\mathbf{x}) = \sum_{n=1}^N y_n \alpha_n^* K_{nx} + b^*$$

נחשב את ערך הפונקציה בנקודות הקיצוניות $\mathbf{x}_1$ ו-$\mathbf{x}_2$ על ידי הפרדת שני האיברים הראשונים בסכום:

$$f(\mathbf{x}_1) = y_1 \alpha_1^* K_{11} + y_2 \alpha_2^* K_{12} + v_1 + b^*$$ $$f(\mathbf{x}_2) = y_1 \alpha_1^* K_{12} + y_2 \alpha_2^* K_{22} + v_2 + b^*$$

נחסיר את המשוואות ונבודד את הביטוי $v_1 - v_2$:

$$v_1 - v_2 = f(\mathbf{x}_1) - f(\mathbf{x}_2) - y_1 \alpha_1^* (K_{11} - K_{12}) - y_2 \alpha_2^* (K_{12} - K_{22})$$

נציב את אילוץ השוויון של המצב הקודם $y_1 \alpha_1^* = y_1 \gamma - y_2 \alpha_2^*$. לאחר סידור וקיבוץ איברים לפי הגדרת $\eta$, נקבל את הקשר המדויק:

$$v_1 - v_2 = f(\mathbf{x}_1) - f(\mathbf{x}_2) + \alpha_2^* y_2 \eta - s y_2 \gamma (K_{11} - K_{12})$$

(ד) גזירת נוסחת העדכון המבוססת על שגיאות החיזוי

נציב את הביטוי שקיבלנו עבור $v_1 - v_2$ בסעיף ג' חזרה לתוך משוואת הקיצון מסעיף ב':

$$\eta \alpha_2 = s(K_{11} - K_{12})\gamma + y_2 \left[ f(\mathbf{x}_1) - f(\mathbf{x}_2) + \alpha_2^* y_2 \eta - s y_2 \gamma (K_{11} - K_{12}) \right] - s + 1$$

נשים לב כי האיברים המכילים את $\gamma$ מצמצמים זה את זה לחלוטין מכיוון ש-$y_2 \cdot (-s y_2 \gamma \dots) = -s \gamma \dots$. נותרנו עם:

$$\eta \alpha_2 = \eta \alpha_2^* + y_2 \left( f(\mathbf{x}_1) - f(\mathbf{x}_2) \right) + 1 - s$$

מכיוון ש-$1 - s = y_2(y_2 - y_1)$, ניתן להוציא את $y_2$ כגורם משותף ולסדר מחדש את האיברים באמצעות הגדרת שגיאות החיזוי המוכרות:

$$\alpha_2 = \alpha_2^* + y_2 \frac{(y_2 - f(\mathbf{x}_2)) - (y_1 - f(\mathbf{x}_1))}{\eta}$$

(ה) חיתוך (Clipping) וגזירת החסמים עבור $s = +1$

למה נדרש חיתוך (Clipping)?
נוסחת העדכון שמצאנו בסעיף ד' מתחשבת אך ורק באילוץ השוויון הליניארי. עם זאת, בבעיית ה-SVM קיימים גם אילוצי קופסה קשיחים: $0 \le \alpha_n \le C$. כיוון ש-$\alpha_1$ משתנה אוטומטית בהתאם ל-$\alpha_2$, עלינו לוודא ששני הערכים החדשים יישארו בתוך תחומי הריבוע $[0,C] \times [0,C]$. חיתוך הערך האנליטי מבטיח שהפתרון יישאר חוקי.

גזירת החסמים $L$ ו-$H$ עבור המקרה $s = +1$:

כאשר $s = y_1 y_2 = +1$, המשמעות היא ששני התיוגים זהים ($y_1 = y_2$). אילוץ השוויון הופך ל:

$$\alpha_1 + \alpha_2 = \gamma \implies \alpha_1 = \gamma - \alpha_2$$

נציב קשר זה לתוך אילוצי התחום של $\alpha_1$:

$$0 \le \gamma - \alpha_2 \le C \implies \gamma - C \le \alpha_2 \le \gamma$$

במקביל, נשבב את אילוצי התחום הישירים של המשתנה עצמו $0 \le \alpha_2 \le C$. שילוב שני התנאים יחד מכתיב את גבולות החיתוך הבאים:

  • החסם התחתון ($L$): החסם התחתון המקסימלי האפשרי: $L = \max(0, \gamma - C)$. מכיוון ש-$\gamma = \alpha_1^* + \alpha_2^*$, נקבל: $L = \max(0, \alpha_1^* + \alpha_2^* - C)$.
  • החסם העליון ($H$): החסם העליון המינימלי האפשרי: $H = \min(C, \gamma) = \min(C, \alpha_1^* + \alpha_2^*)$.
